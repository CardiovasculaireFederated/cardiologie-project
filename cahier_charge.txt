# CAHIER DE CHARGES

## Federated Learning with Apache Kafka

---

## 1. PRESENTATION DU PROJET

### 1.1 Objectif Principal
Développer une infrastructure de machine learning fédéré complète intégrant Apache Kafka pour la communication distribuée entre clients et serveur central, permettant l'entraînement décentralisé de modèles de deep learning sur des données hétérogènes.

### 1.2 Contexte et Justification
Ce projet répond aux besoins croissants de privacy-preserving machine learning dans les contextes sensibles (données médicales, financières). L'architecture permet l'entraînement de modèles globaux sans centraliser les données, tout en garantissant une communication fiable et scalable via Kafka.

### 1.3 Périmètre
- Infrastructure Kafka complète avec Docker
- Serveur Flower implémentant FedAvg
- 2 clients simulant des hôpitaux avec données différentes
- Système de monitoring complet (Prometheus/Grafana)
- Documentation technique complète

### 1.4 Exclusions
- Implémentation de mécanismes de privacy différentielle avancés
- Déploiement en production cloud
- Support multi-language (Python uniquement)
- Scalability au-delà de 4 clients simulés
- Optimisations de compression de modèles
